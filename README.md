# KubeDriftGuard

Real-time Kubernetes configuration drift detection and agentic self-healing engine.

## Overview

KubeDriftGuard is a Kubernetes controller that continuously watches live cluster state against declared GitOps manifests, detects configuration drift in real-time, and triggers self-healing workflows with AGENTS.md-driven remediation strategies.
